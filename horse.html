H.O.R.S.E.

Challenge mode between gooners

How it works

One player proposes a task on any level (even outside the list). The other player must match it exactly.

  • Proposer attempts the task first.
  • If the proposer fails → Re-do (no letter given).
  • If the proposer succeeds → the opponent must copy it.
  • If the opponent fails → they get a letter (H → O → R → S → E).
  • If the opponent succeeds → no letter, turn switches.
  • Every time a letter is added, a new task must be set.
  • First to get all 5 letters loses.
