HOW DOES THE POINT SYSTEM WORK?

The G_S demon list uses a points system to rank completed levels. Each level has its own point value.

01 — COMPLETION

Points are awarded only when a player reaches 100% on a level. Partial progress does not count towards the total score.

02 — LEVEL VALUES

Every level has a specific point value. More difficult levels generally award more points.

03 — LIVE STATISTICS

Player statistics are automatically updated whenever an approved record changes in the G_S demon list database.
